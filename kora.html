Kahu Hutton

KORA, founder and developer

2024.

KORA is an LMS plugin that generates and grades course content. It uses retrieval-augmented generation against a university's own material, so what it produces comes from the course rather than from the model's general knowledge. Funded by Google Cloud. Entered in the Lee Kuan Yew Global Business Plan Competition.

What I built

  • The full-stack web app in React and Next.js, containerised with Docker, on cloud-hosted databases with integrated authentication and authorisation.
  • A standalone LMS plugin and RAG status-tracking tool serving 100+ daily users, built with a team of three.
  • Automated cloud deployment pipelines.
  • The product from concept and UI through to user feedback, with close contact with the people using it.
