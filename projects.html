Snippetbox

github.com/CARWHO/snippet-box

A Go web app from Let's Go by Alex Edwards. Paste some text, give it an expiry, share the link.

This was a Go learning exercise before I went and built a more proper web app. Every line of code here was written by hand, nothing generated.

  • Routing with the standard library mux, method-based and wildcard routes
  • MySQL through database/sql, with models owning all database access
  • html/template with a template cache, static files embedded in the binary
  • Form parsing, decoding, and validation
  • Sessions with scs, signup and login with bcrypt
  • CSRF protection with nosurf, TLS, secure headers, structured logging
  • Middleware chains with alice
  • Unit and integration tests, with mocks for the models

Chapter notes are in the repo. I wrote them in my own words from my understanding of each section, then went back through them at the end to make sure I actually understood everything I had built.

FPGA reaction timer

March 2025. github.com/CARWHO/FPGA-Reaction-Timer · report (pdf)

A reaction timer in VHDL on a Nexys-4 DDR. A finite state machine controls the sequence, seven-segment displays show the statistics, and random delays stop the user anticipating the prompt.

  • VHDL finite state machine controlling the sequential timer process.
  • Interface from LEDs, seven-segment displays, and push buttons, with error handling for premature inputs.
  • An ALU computing average, best, and worst reaction times, validated with Vivado simulations.
  • Configurable test parameters and random delay generation.

STM32 step counter

2024. github.com/CARWHO/Step-Counter

Firmware for a step counter on an STM32 Nucleo board, with an LSM6DS IMU for step detection and an SSD1306 OLED for display.

  • Step detection from a moving-average filtered accelerometer signal. The squared magnitude of the three axes is compared against a threshold on a rising edge, with hysteresis to stop double counting.
  • Modular C firmware under cooperative multitasking: a super-loop polls each module at a fixed rate, and every task was timed with a hardware timer and checked against its period. Roughly 40% CPU load.
  • User-settable step goals via potentiometer, audible alerts, a test mode that simulates steps from the joystick, and UART telemetry toggled by a button.
  • Joystick and hardware buttons drive the display modes: step count, distance, goal, and progress.

Halo-Vision

December 2023 to August 2024. Project lead. github.com/CARWHO/Halo-Vision · project report (pdf, 24 MB) · CFD report (pdf)

An open-source heads-up display for motorcycle helmets: turn-by-turn navigation and safety notifications, with custom PCBs, firmware, and a mobile app.

  • Custom PCBs designed for power efficiency, replacing the development-board prototype.
  • Helmet mounts and enclosures developed for a range of riding speeds.
  • CFD and wind tunnel testing of the forces on the mount at riding speed.
  • Everything open source: hardware, firmware, and app files on GitHub.
  • Built with app developers, hardware engineers, and industry contacts.

Accent Productions, wind load analysis

March 2024. report (pdf)

A wind load analysis on a stage cover in Autodesk CFD and SolidWorks. The report reconciled discrepancies between the client's own tests and the CFD results, evaluated wind forces from 10 to 60 km/h, and recommended changes to rope selection and mounting.

  • Found a 19% variance in safety margins between the client's tests and the simulation.
  • Delivered recommendations on rope selection and secure mounting.
  • Ran the whole process: geometry, meshing, simulation setup, convergence studies, post-processing, and the report.

Accent Productions is my dad's company. It later became the first pilot customer for HireOS.
