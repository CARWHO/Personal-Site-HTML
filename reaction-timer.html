FPGA reaction timer

March 2025. github · report (pdf)

A reaction timer in VHDL on a Nexys-4 DDR. An FSM drives the sequence, the seven-segment displays show your stats, and a random delay before the prompt means you can't cheat by anticipating it haha. LEDs and push buttons for the interface, with error handling if you press early. An ALU works out average, best, and worst times, checked in Vivado simulation. Test parameters are configurable.
